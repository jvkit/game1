# game1

> 基于 Phaser 的 Shooter Game 射击小游戏

<p><img src="https://img.shields.io/badge/lang-HTML-blue?style=flat-square"/></p>

## 简介
使用 Phaser 游戏引擎开发的网页射击小游戏（Shooter Game），包含完整的场景、角色、音效与资源，可直接在浏览器中运行。

## 技术栈
Phaser（JavaScript 游戏引擎） / HTML5 / 静态资源（图片、音频）

## 快速开始
无需构建，用浏览器打开 `index.html` 即可游玩，或本地起静态服务器：

```bash
python3 -m http.server 8000
```
